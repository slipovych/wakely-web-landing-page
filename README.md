# Wakely Landing Page (Legacy) 🌐

A simple, single-page promotional website (landing page) designed to showcase the concept and features of the Wakely smart alarm application. 

## 🛠 Tech Stack
* **Structure:** HTML
* **Styling:** CSS
* **Interactivity:** JavaScript, jQuery

## ⚙️ UI / UX Features

* **Smooth Scrolling Navigation:** Clicking on the navigation menu buttons triggers a smooth scroll to the corresponding section of the page, eliminating abrupt jumps.
* **Introductory Animations:** The hero/intro block features a custom text appearance animation with a glowing effect to catch the user's attention upon loading.
* **Dynamic Image Movement:** Horizontal image sliding and movement effects are implemented via jQuery, adding a dynamic feel to the otherwise static layout.

## 📝 Project Status & Context
This is a completed, legacy front-end project built purely as a visual showcase. It relies on classic web technologies without modern build tools, frameworks (like React/Vue), or backend architecture. It serves strictly as a companion promotional piece for the main Android application.
